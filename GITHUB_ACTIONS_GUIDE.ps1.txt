# ┌─────────────────────────────────────────────────────────────┐
# │  Step 1: 浏览器打开 GitHub 创建一个新仓库                     │
# └─────────────────────────────────────────────────────────────┘
#
#  👉 https://github.com/new
#  Repository name:  AnkiNotes  (或你喜欢的名字)
#  ⚠️  不要勾选 "Add a README file" / ".gitignore" / "License"
#      否则 push 时会冲突。
#  Visibility: Public 或 Private 都可以 (Actions 对 Private 免费额度有限)
#
#  创建完成后，复制仓库地址，形如:
#    https://github.com/你的用户名/AnkiNotes.git
#

# ┌─────────────────────────────────────────────────────────────┐
# │  Step 2: 本地执行 push 代码到 GitHub (下方二选一)             │
# └─────────────────────────────────────────────────────────────┘

# --- 方式 A：直接用下面这个 PowerShell 命令 (推荐) ---
# 将下面的 URL 替换为你真实的仓库地址后执行：
#
#   $YOUR_REPO = "https://github.com/你的用户名/AnkiNotes.git"
#   git branch -M main
#   git remote add origin $YOUR_REPO
#   git push -u origin main
#
# 如果 git push 时要求密码，要使用 GitHub Personal Access Token
#  (Settings > Developer settings > Personal access tokens > repo 权限)

# --- 方式 B：用 SSH 方式 (更流畅，不需要每次输密码) ---
#   $YOUR_SSH_REPO = "git@github.com:你的用户名/AnkiNotes.git"
#   git branch -M main
#   git remote add origin $YOUR_SSH_REPO
#   git push -u origin main

# ┌─────────────────────────────────────────────────────────────┐
# │  Step 3: 触发 GitHub Actions 构建                            │
# └─────────────────────────────────────────────────────────────┘
#
#  push 之后，GitHub 会自动跑第一个 Job (Simulator Build，3-5 分钟)。
#  访问: https://github.com/你的用户名/AnkiNotes/actions
#
#  ✅ Job 1 (Simulator Build) —— 自动执行，无需手动触发
#     - 验证代码能否完整编译通过
#     - 产出: AnkiNotes-Simulator.zip (Mac 上 xcrun simctl 可装到模拟器)
#
#  📲 Job 2 (Device IPA) —— 需要手动触发，因为真机构建更慢更耗额度
#     触发方式 ① 最方便：Action 页面 → 左侧选 "AnkiNotes iOS Build"
#              → 右侧 "Run workflow" 绿色按钮 → Run workflow
#
#     触发方式 ② 提交代码时：
#              git commit --allow-empty -m "release: 构建 [build-ipa]"
#              git push
#              （commit message 里包含 [build-ipa] 就自动触发 IPA 构建）
#
#     - 产出: AnkiNotes-iOS-IPA (zip 里是 AnkiNotes.ipa)
#     - 保留 30 天

# ┌─────────────────────────────────────────────────────────────┐
# │  Step 4: 下载 IPA 并用 Sideloadly 安装到 iPhone              │
# └─────────────────────────────────────────────────────────────┘
#
#  4.1 GitHub Actions 页面 → 跑完的 workflow → 下方 Artifacts
#      → 点 AnkiNotes-iOS-IPA 下载 zip → 解压得到 AnkiNotes.ipa
#
#  4.2 Windows 安装 Sideloadly: https://sideloadly.io/  (免费)
#      同时安装 iTunes (Microsoft Store 里搜 iTunes 免费装，用于驱动)
#
#  4.3 iPhone 用 USB 连电脑 → 手机上弹出 "是否信任" → 点 信任
#
#  4.4 打开 Sideloadly:
#        • iDevice: 选择你的 iPhone
#        • Apple account: 填你自己的 Apple ID (免费账号即可，7天到期重签)
#        • 把 AnkiNotes.ipa 拖进中间大框
#        • 点 Start
#        • 弹出输入密码，填 Apple ID 的专用密码 (非登录密码！)
#          → AppleID 管理页面: https://appleid.apple.com
#          → 登录 → App 专用密码 → 生成 → 复制到 Sideloadly
#
#  4.5 iPhone 上:
#        设置 → 通用 → VPN 与设备管理 → 找到你的 Apple ID → 点击 信任
#        返回桌面即可看到 "Anki 笔记" App，打开开始使用！
#
#  4.6 7 天到期后（免费 Apple ID 限制）：
#      手机连电脑 → 打开 Sideloadly → 再点一次 Start 重签即可。

# ┌─────────────────────────────────────────────────────────────┐
# │  后续日常开发流程                                            │
# └─────────────────────────────────────────────────────────────┘
#
#  修改代码 → git add . → git commit -m "xxx [build-ipa]" → git push
#  → GitHub 自动构建 → 下载新 IPA → Sideloadly 安装覆盖 (数据不丢)
#
#  不想每次都构建 IPA 的话，省略 [build-ipa]，只跑 Simulator Job，
#  用于快速验证代码是否能编译通过；想上新版本时再手动点一次 IPA Job。
